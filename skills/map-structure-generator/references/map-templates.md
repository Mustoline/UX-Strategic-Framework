# Map templates

Use these templates as starting points. Adapt them to the activity, package, and scope.

## Journey-step map scaffold

```markdown
# Journey-step map

## Mapping objective

[What decision or question this map is meant to support]

## Step in scope

[The selected journey step or workflow moment]

| Section | What to capture |
| --- | --- |
| Actors | [User, staff, or team involved at this step] |
| Actions | [What happens at this step today] |
| Touchpoints | [Screens, channels, or service touchpoints involved] |
| Systems or dependencies | [Systems, handoffs, or approvals involved] |
| Friction points | [Where time, confidence, or momentum is lost] |
| Implications | [Why the breakdown matters to the next decision] |
```

## Legend template

```markdown
## Legend

* `U`: User action or user need
* `T`: Touchpoint or channel
* `S`: System or platform
* `O`: Operational action or back-stage process
* `D`: Dependency or handoff
* `B`: Breakdown, pain point, or loss of value
* `R`: Risk, assumption, or validation point
```

## Breakdown and dependency prompt set

```markdown
* Where is time lost here?
* Where do users or staff lose clarity, trust, or momentum?
* Which handoff, system, or approval creates friction?
* Where is ownership unclear?
* Where does work get duplicated or re-done?
* Which issue has the biggest delivery, service, or commercial implication?
* Which part of the map still needs validation rather than confident reporting?
```
