# Journey-step templates

Use these templates as starting points for Package A journey-step mapping.

## Mapping objective

```markdown
## Mapping objective

### Selected step in scope

[The bounded step, workflow slice, or feature-area moment being mapped]

### Decision this map should support

[The decision the sprint needs to make easier]

### Target users or staff groups

* [Group]
* [Group]
```

## Journey-step map scaffold

```markdown
# Journey-step map

| Section | What to capture |
| --- | --- |
| Actors | [Who is involved in this step] |
| Current actions | [What happens today] |
| Touchpoints and channels | [Where the interaction happens] |
| Systems and dependencies | [Systems, approvals, handoffs, or data inputs involved] |
| Friction points | [Where time, confidence, or momentum is lost] |
| Internal implications | [What creates extra effort, delay, or rework] |
```
