# Option review templates

Use these templates as starting points for Package A option review work.

## Option review objective

```markdown
## Option review objective

### Decision this review should support

[The decision the sponsor needs to make after the sprint]

### Problem area in scope

[The selected problem, journey step, or workflow area]

### Options being compared

* [Option A]
* [Option B]
```
