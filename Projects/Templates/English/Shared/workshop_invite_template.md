# Workshop invite template

## Purpose

Use this template to invite participants to a real-world workshop in Package A, Package B, or Package C.

The goal is to make the purpose, scope, expected contribution, and practical details clear enough that the right people show up prepared.

## When to use it

Use this template for:

* sponsor workshops
* scoping workshops
* mapping sessions
* concept-direction reviews
* validation workshops

## Required structure

Use this order in the invite:

1. `Why this workshop is happening`
2. `What decision or output it supports`
3. `What we will cover`
4. `Who should attend`
5. `What to prepare`
6. `Practical details`
7. `What happens after`
