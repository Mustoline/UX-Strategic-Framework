# Current journey mapping template

Use this template when you need to map the current-state journey in a mapping session, especially in Package B Activity 2.1.

The template is designed to show:

* the most important phases in the current journey
* what the user is trying to achieve in each phase
* where friction appears
* which teams, systems, and handoffs shape the experience
* which opportunity areas and decision criteria should be carried forward

## How to use it

1. Start with the real current-state phases, not the desired future version.
2. Describe the user's goal and need in each phase.
3. Note the main friction, uncertainty, or barrier by phase.
4. Make teams, systems, and handoffs visible when they affect the experience.
5. Finish by marking the few breakdowns and opportunity areas that matter most to the next decision.
