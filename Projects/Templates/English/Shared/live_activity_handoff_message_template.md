# Live activity handoff message template

## Purpose

Use this template after a stage has been validated and the next step is a real-world activity such as a workshop, interview, evidence review, or mapping session.

## Required message structure

Use this exact order in the main user-visible response:

1. `Next live activity`
2. `Why this step now`
3. `Estimated time`
4. `Who should be involved`
5. `What to prepare or gather`
6. `Files to use`
7. `Come back with`
8. `Optional support`

## Formatting rules

* Keep the message short, practical, and explicit
* Put the actual handoff in the main response, not in commentary
* Link the seeded project input file in `01-inputs/`
* Link the relevant facilitator guide
* Link any supporting template, question guide, or tool file that helps the activity run well
* Do not start collecting the activity notes in chat unless the user explicitly asks to simulate or prepare the activity inside the tool

## Example

**Next live activity**
Activity 1.2: Evidence baseline review

**Why this step now**
We have agreed the decision frame. The next step is to test whether checkout friction, basket trimming, or a broader upstream issue is best supported by the available evidence.

**Estimated time**
2-4 hours, depending on evidence availability and quality

**Who should be involved**
* Analytics owner
* Ecommerce product owner
* Anyone who can supply support, sales, or behavior data for the step in scope

**What to prepare or gather**
* Analytics for the selected step
* Segmentation by device, customer type, or basket size where possible
* Any support themes, sales input, or prior research already available

**Files to use**
* Project input file: `01-inputs/package_a_activity_1_2_input.md`
* Facilitator guide: `Packages/English/Package_A_facilitator_guide.md`

**Come back with**
Return with the completed evidence notes in the seeded project input file so synthesis and validation can continue.

**Optional support**
If you want, ask me to help prepare the evidence request or shape the review before you run it.
